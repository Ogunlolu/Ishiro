# Ishiro

Split the trip. Keep the friends.

A mobile app (iOS and Android) for friends on group trips: record who paid for
what, see who owes whom, and end the trip square.

**Status:** building. So far: an empty app with the brand colours and font,
and automatic checks.

## Run it

```bash
npm install
```

```bash
npm start
```

Then scan the QR code with the Expo Go app on your phone.

## Check it

```bash
npm run verify
```
